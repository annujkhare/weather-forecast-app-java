# Weather Forecast Application

A simple weather forecast application built using Java and Spring Boot.

## Technologies Used

- Java
- Spring Boot
- REST API
- JSON
- HTML
- JavaScript
- Open-Meteo API

## Features

- Search weather by city
- Current temperature
- Current humidity
- 5-day temperature forecast
- Real-time weather API integration

## How to Run

1. Clone the repository
2. Open the project in VS Code
3. Run:

./mvnw spring-boot:run

4. Open:

http://localhost:8080
